World News, Friday 27 November 2026, in one image: a self-drawn 1024 x 1024 newspaper front page covering the day's six biggest stories — the tanker explosions in the Strait of Hormuz, the diesel tanker sunk off Ibiza, Russian strikes on Ukraine, Israeli strikes in Gaza, the Thanksgiving storm on the US East Coast, and the US approval of SpaceX's million-satellite plan — with the Colombia siege, UK migration and the EU Ukraine loan as footer briefs.

The program paints the whole page in memory with a hand-written 5x7 bitmap font and a small PNG encoder, using only the Node standard library. No network, no input files, no clock: two runs write identical bytes.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
